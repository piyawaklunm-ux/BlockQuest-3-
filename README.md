# BlockQuest-3-
BlockQuest: ผจญภัยเรียนรู้ในโลก 3 มิติ  เกมจำลองโลกสามมิติที่ผู้เล่นสามารถสำรวจสถานที่ต่าง ๆ ทำภารกิจ ตอบคำถามเพื่อสะสมเหรียญ และปลดล็อกไอเทมภายในเกม

รายละเอียดของเกม
BlockQuest เป็นเกมการเรียนรู้ในรูปแบบสามมิติที่เปิดเล่นผ่านเว็บเบราว์เซอร์ ผู้เล่นสามารถเลือกตัวละคร เดินสำรวจหมู่บ้านและเมือง เข้าไปยังสถานที่ต่าง ๆ เพื่อทำภารกิจตอบคำถาม และสะสมคะแนนเพื่อใช้ซื้อไอเทมในร้านค้า

ภายในเกมประกอบด้วยระบบหลัก ได้แก่
- ระบบตัวละคร: เลือกตัวละครได้หลายรูปแบบ
- ระบบแผนที่: สำรวจหมู่บ้านและเมือง และวาร์ประหว่างแผนที่ได้
- ระบบภารกิจ: ตอบคำถามเพื่อรับเหรียญและบันทึกความสำเร็จ
- ระบบร้านค้า: ใช้เหรียญซื้อชุดและอาวุธภายในเกม
- ระบบกระเป๋าไอเทม: แสดงรายการสิ่งของที่ซื้อแล้ว
- ระบบมุมมอง: สลับมุมมองบุคคลที่ 1 และบุคคลที่ 3
  
วิธีการเล่น
ปุ่มควบคุม	วิธีใช้งาน
W A S D	เคลื่อนที่ตัวละคร
Spacebar	กระโดด
E	โต้ตอบกับวัตถุหรือประตูที่อยู่ใกล้
M	วาร์ประหว่างหมู่บ้านกับเมือง
เมาส์	หมุนมุมมองและเลือกคำตอบ
ปุ่มมุมมอง	สลับมุมมองบุคคลที่ 1 และ 3
ขั้นตอนการเล่น
1. กดเริ่มเกมและเลือกตัวละครที่ต้องการ
2. ใช้ปุ่มควบคุมเดินสำรวจแผนที่
3. เข้าใกล้วัตถุหรือสถานที่ที่มีภารกิจ แล้วกด E
4. อ่านคำถามและเลือกคำตอบที่ถูกต้อง
5. รับเหรียญเมื่อทำภารกิจสำเร็จ
6. นำเหรียญไปซื้อไอเทมและตรวจสอบสิ่งของในกระเป๋า
7. กด M เพื่อเดินทางไปยังอีกเมืองได้ทันที โดยไม่จำเป็นต้องทำภารกิจทั้งหมดให้เสร็จ
